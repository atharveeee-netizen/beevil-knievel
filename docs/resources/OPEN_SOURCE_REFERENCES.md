# Beevil Knievel — Open-Source Repositories & Dataset References Index

---

## 🐙 Open-Source GitHub Repositories

1. **[LongHive (Edge AI + LoRaWAN Smart Beehive System)](https://github.com/evandiewald/LongHive)**
   * **URL**: `https://github.com/evandiewald/LongHive`
   * **Usage**: Low-power ESP32/STM32 sleep states & LoRa binary payload formatting.

2. **[beeSSL / HUnEE-B Benchmark](https://github.com/Hguimaraes/beeSSL)**
   * **URL**: `https://github.com/Hguimaraes/beeSSL`
   * **Usage**: Pre-trained machine learning weights for classifying acoustic frequency signatures.

3. **[Hiveeyes bScale Telemetry](https://github.com/hiveeyes/bScale)**
   * **URL**: `https://github.com/hiveeyes/bScale`
   * **Usage**: Thermal compensation math for HX711 strain gauge scales.

4. **[Bioacoustic MCWaveGAN](https://github.com/KumuduS/Bioacoustic_MCWaveGAN)**
   * **URL**: `https://github.com/KumuduS/Bioacoustic_MCWaveGAN`
   * **Usage**: Synthetic audio generation for rare bee acoustic events.

5. **[RadioLib C++ LoRa Library](https://github.com/jgromes/RadioLib)**
   * **URL**: `https://github.com/jgromes/RadioLib`
   * **Usage**: Direct driver support for STM32WL / SX126x sub-GHz radios.

6. **[DallasTemperature 1-Wire Library](https://github.com/milesburton/Arduino-Temperature-Control-Library)**
   * **URL**: `https://github.com/milesburton/Arduino-Temperature-Control-Library`
   * **Usage**: Reading multi-drop DS18B20 digital temperature sensors on a single GPIO line.

## 📊 Public Audio Datasets

1. **Zenodo "To Bee or Not to Bee" Dataset**
   * **URL**: `https://zenodo.org/records/1321278`
   * **Usage**: Training set for 200–400 Hz acoustic swarming and queenlessness detection.

2. **Utah State University BeePi Audio Dataset**
   * **URL**: `https://usu.app.box.com/v/BeePiAudioData`
   * **Usage**: Multi-season continuous acoustic hive recordings.
