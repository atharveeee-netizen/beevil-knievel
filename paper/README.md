# Beevil Knievel — IEEE Conference Paper

**Title:** Beevil Knievel: An Edge-Native LoRa Cyber-Physical System for Non-Invasive Honeybee Colony
Monitoring — Architecture, Reproducible Validation, and Feasibility Analysis

**Authors:** Atharve Dahima, Srajan Mishra, Vishal Sharma

This folder contains the LaTeX source (IEEEtran, conference mode), the compiled PDF, and every script
needed to regenerate the numbers, tables and figures in Section V of the paper from this repository.

```
paper/
├── main.tex              IEEEtran conference source
├── references.bib        bibliography (BibTeX)
├── main.pdf              compiled paper
├── run_all.sh            regenerates all analysis figures and result files
├── analysis/             analysis scripts (Python)
├── figs/                 figures used by main.tex (+ PNG previews of generated plots)
└── results/              JSON outputs behind every number quoted in the paper
```

## Build the PDF

```bash
cd paper
latexmk -pdf main.tex          # or: pdflatex main && bibtex main && pdflatex main && pdflatex main
```

The source also compiles unchanged on Overleaf (upload the `paper/` folder; IEEEtran is built in).
Before submission, replace the `[Department]`, `[Institution]`, `[City]` and `[email address]`
placeholders and complete the acknowledgment.

## Reproduce the results

From the repository root:

```bash
pip install numpy scipy matplotlib pandas scikit-learn joblib fastapi uvicorn httpx pydantic pytest pillow
bash paper/run_all.sh
```

## Repository issues found while writing the paper

1. **Alert flags collide with the tilt field.** Firmware ORs `0x80/0x40/0x20/0x10` into `tilt_deg`; the
   gateway reads that byte as degrees. Low battery → "theft", CUSUM queen-loss alert → HTTP 422 (dropped).
   Fix: add a flags byte and a sequence number (35-byte frame, 77.1 ms at SF7).
2. **CUSUM threshold units and tuning.** `h = 1.2` is in °C·sample, not °C·h; with autocorrelated brood
   temperature the firmware detector false-alarms within ~10 h. Page CUSUM with k = 0.25 °C, h = 8 gives a
   34-day in-control run length (recalibrate on field data).
3. **Acoustic engine is gain-dependent.** The absolute threshold `max_val < 5.0` drives accuracy to chance
   below −24 dBFS; DFT probes ripple 14–23 dB in-band. Use FFT band integration and relative energies.
4. **FFT configuration inconsistency.** 16 kHz/256 gives 62.5 Hz bins (one bin for 100–180 Hz); 2 kHz/256
   aliases the 800–1200 Hz band. Recommended: decimate 16 kHz by 4, 512-point FFT (7.81 Hz bins).
5. **Gateway radio path.** `gateway/lora_receiver.py` has an SPI stub, but the installed Waveshare HAT
   (Ebyte E22-900T22S) is a UART module. The v1.0 node transmitter only blinks an LED for 60 ms.
6. **HFSS model.** The lumped port touches only one conductor, so the antenna model is not excited
   correctly; fix before quoting S11 or gain.
7. **Range claims.** 15 km follows from free-space loss; with 0.5 m / 4 m antenna heights the two-ray model
   gives 1.3 km at SF7 (0.62 km with 50 m of foliage).
8. **Documentation inconsistencies.** Cell capacity (1000/2600/3000 mAh), FFT size (128/256/512),
   sampling rate (2/16 kHz), payload (32/33 bytes) and airtime (18.2/61.7/71.94 ms) vary between files;
   71.94 ms is correct for 33 bytes at SF7/125 kHz/CR 4/5.
