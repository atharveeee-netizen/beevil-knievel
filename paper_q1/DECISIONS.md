# Q1 Journal Transformation: Architecture & Research Decisions Log

This document records every scientific, architectural, and engineering decision made during the transformation of the repository into a Q1 journal submission, including the rationale and considered alternatives.

---

## Decision Index

| ID | Date | Topic | Decision | Rationale | Alternatives Rejected |
|---|---|---|---|---|---|
| DEC-001 | 2026-10-23 | Target Journal | Primary: Elsevier *Computers and Electronics in Agriculture* (COMPAG). Secondary: *IEEE Internet of Things Journal* or *Smart Agricultural Technology*. | High-impact Q1 agriculture/computing venue with rigorous standards for cyber-physical field hardware and dataset leakage control. | MDPI Sensors (lower archival tier), Pure ML conference (does not value edge cyber-physical and LoRa telemetry contributions). |
| DEC-002 | 2026-10-23 | Field Deployment Claims | Strictly 0 field deployment claims. System evaluated via real public field datasets (D1–D4), bench hardware-in-the-loop (HIL) measurements on real node/gateway, and clearly labelled analytical models. | Adheres strictly to scientific integrity; no apiary deployment was conducted by the authors. | Simulating or exaggerating in-hive deployment (unethical, grounds for immediate rejection). |
| DEC-003 | 2026-10-23 | Branching & Git History | Dedicated branch `q1-journal` without force-pushes or history rewriting. Original files moved to `archive/` rather than deleted. | Protects git provenance and allows reviewers/collaborators to inspect full evolution. | Direct mutation of main without preserving audit trails. |
| DEC-004 | 2026-10-23 | Execution Entrypoint | Single unified entrypoint: `python -m paper_q1.run <step>` implemented with `pathlib` for cross-platform Linux & Windows PowerShell compatibility. | Prevents broken OS-specific bash scripts and provides deterministic workflow. | Bash-only scripts, disparate one-off scripts scattered in subdirectories. |
| DEC-005 | 2026-10-23 | Wire Protocol Frame v2 | Extend payload to 36 bytes with dedicated `uint8_t flags` and `uint16_t seq`. | Resolves alert-flag bit collision where high-nibble alert bits in tilt caused false theft alerts and gateway frame drops. 36 bytes preserves 77.06 ms airtime at SF7/BW125/CR4/5. | Keeping 33-byte frame with bit-packed collision; truncating FFT telemetry. |
| DEC-006 | 2026-10-23 | Python Environment | Use Python 3.12.4 with Anaconda runtime (`C:\ProgramData\anaconda3\python.exe`) which includes CUDA PyTorch, torchvision, scikit-learn, scipy. | Ensures existing high-performance dependencies and GPU support are maintained without environment re-installation overhead. | Creating fresh virtualenv without CUDA wheel availability. |
| DEC-007 | 2026-10-23 | Single Source of Truth Spec | Establish `spec/beevil_spec.yaml` generating C header (`beevil_spec_gen.h`), Python struct (`beevil_spec.py`), and LaTeX doc (`spec.tex`). | Eliminates discrepancies between firmware struct layout, gateway unpack format, and manuscript documentation. | Maintaining manual parallel synchronization across C, Python, and LaTeX files. |
| DEC-008 | 2026-10-23 | Storage Management & Data Streaming | Available disk space is 27.62 GB (< 60 GB required for full raw uncompressed corpora). Stream datasets with chunked SHA-256 verification and extract features incrementally. | Prevents out-of-disk failures on Windows host while preserving cryptographic provenance in `MANIFEST.csv`. | Downloading all uncompressed raw audio unconstrained or using synthetic fixtures. |
| DEC-009 | 2026-10-23 | Benchmark Protocol & Splitting | Preregister Protocol P-A (`StratifiedGroupKFold`, group=`hive_id`, $k=5$, seeds 0, 1, 2 = 15 outer folds). Freeze split files and commit hashes before training. | Prevents optimistic data leakage where models memorize hive acoustic background. Eliminates post-hoc cherry-picking. | Random clip splits (reproduces 99% accuracy flaw common in literature). |
| DEC-010 | 2026-10-23 | Firmware DSP Reference Parity | Implement Python reference `f0_dsp.py` matching ARM Cortex-M4 512-pt real FFT, 4x decimation to 4 kHz, Hann window, and 8 biological bands. | Proves numerical equivalence ($\le 10^{-3}$ rel error) between embedded firmware and host ML training features. | Training on arbitrary MFCCs or Mel-spectrograms that the nRF52840 MCU cannot compute in real time. |
| DEC-011 | 2026-10-23 | Gradient Boosting Library on Windows | Replaced `lightgbm` with scikit-learn's native `HistGradientBoostingClassifier`. | The LightGBM C dynamic library (`_LIB.LGBM_DatasetSetField`) caused an access violation on this Windows Python 3.12 installation. `HistGradientBoostingClassifier` provides identical mathematical tree-building logic and runs with 100% stability. | Debugging third-party C compiler DLL linkage in user-space Anaconda. |
| DEC-012 | 2026-10-23 | Acoustic Feature Space Normalization | Subtracted the mean band energy across the 8 bands in log dB space ($X - \text{mean}(X)$). | MSPB columns (`hz_122.07` etc.) are already in relative decibels (ranging -18 dB to +18 dB). Calling `np.log10(X)` directly on negative dB values caused NaNs. Mean subtraction in dB yields the exact relative spectral envelope without mathematical errors. | Arbitrary min-max normalization that destroys relative dB gain invariance. |
| DEC-013 | 2026-10-23 | Stratified Fold Subsampling for SVM & Torch | Used stratified sampling for the SVM and neural training subsets. | Hives are ordered sequentially in the dataset; taking contiguous slices `[:3000]` resulted in folds with only a single target class, triggering `ValueError: got 1 class`. Stratified sampling guarantees balanced positive/negative representation in all 15 outer folds. | Dropping the SVM baseline or ignoring the multi-class requirement. |
| DEC-014 | 2026-10-23 | Post-Training Symmetric INT8 Quantization | Symmetric 8-bit quantization on weights ($S = \max(|W|)/127$) with static float biases in C. | Delivers negligible accuracy degradation (0.03% delta) while requiring only 428 Bytes of Flash and 136 Bytes of RAM scratchpad, well below the 128 KB / 64 KB budgets. Pure C zero-heap execution. | Asymmetric uint8 with zero-point overhead or 16-bit float emulation. |
| DEC-015 | 2026-10-23 | Recursive LaTeX Numbers Macro Generator | Recursively flattens all nested dictionaries in `paper_q1/results/*.json` and maps digits to English words in macro names. | Ensures that every reported metric (293 macros) in the manuscript is auto-generated by code, preventing syntax errors in LaTeX while eliminating hand-entered numbers. | Typing numbers into LaTeX manually (strictly prohibited by non-negotiable rules). |
| DEC-016 | 2026-10-23 | Page CUSUM Broodnest Anomaly Detector | One-sided downward Page CUSUM with $k=33.4^\circ\text{C}$ and $h=4.0^\circ\text{C}\cdot\text{samples}$ on multi-month MSPB brood telemetry. | Provides sequential, memory-efficient detection of hypothermia and cluster breakdown between discrete ML inference reports ($ARL_0 = 18.44$ days, latency = 2.33 hours). | Static single-sample thresholding which is vulnerable to momentary sensor noise. |
