\begin{abstract}
Commercial honeybee (\textit{Apis mellifera}) pollination underpins \$17B in annual crops, yet managed colonies suffer annual mortality exceeding 55.6\%. Manual hive inspections chill the brood nest by up to $-12^\circ\text{C}$ and fail to catch swarming or queen distress before collapse. BEEVIL KNIEVEL is an autonomous cyber-physical telemetry node and custom gateway reader providing continuous inside-hive visibility without colony disturbance. Evaluated as a functional bench prototype, the custom node integrates a Nordic nRF52840 MCU, Semtech SX1262 LoRa, NIST-traceable TI TMP117 ($\pm 0.1^\circ\text{C}$) brood RTD, 5-point Maxim DS18B20 1-Wire grid, and I2S MEMS acoustics. On-node CMSIS-DSP 256-point Real FFT and recursive Page's CUSUM anomaly filtering detect pre-symptomatic swarming and queenless cooling drift ($0.85\text{ mWh/day}$ budget, 18+ month solar autonomy). Telemetry is captured by a custom Raspberry Pi 3B+ gateway reader over IN865 LoRa (4.2~km calculated LOS). All 27 automated system tests pass cleanly.
\end{abstract}

\section{Real-World Problem \& Observability Gap}
Commercial apiaries manage hundreds of hives per yard, limiting human inspections to once every 14--21 days. Opening hives disrupts propolis seals and chills delicate brood larvae ($34.5^\circ\text{C}$ core) by up to $-12^\circ\text{C}$, causing wing deformities and stress \cite{ferrari2008}. Crucially, swarming occurs after a narrow 24--48\,hr acoustic surge, and queen mortality triggers subtle thermal drift ($-0.02^\circ\text{C}/\text{hr}$) undetectable by manual spot-checks. BEEVIL KNIEVEL bridges this gap via hermetic inside-hive telemetry.

\section{System Architecture \& Custom Hardware}
As shown in Fig.~\ref{fig:architecture}, the system comprises an autonomous \textbf{Field Sensor Node} and a custom \textbf{Edge Gateway Reader}.

\textbf{Custom Sensor Node Carrier PCB:} Designed by the team around the RAKwireless RAK4631 module (Nordic nRF52840 ARM Cortex-M4F @ 64~MHz, FPU, 1~MB Flash, 256~KB SRAM + Semtech SX1262 LoRa). The custom carrier features an active high-side P-FET switch on \texttt{P0.29}, cutting divider leakage during sleep to achieve zero draw. Switched rail \texttt{WB\_IO2} isolates sensor power, achieving a validated deep-sleep draw of only \textbf{18~$\mu\text{A}$} [MEASURED]. Solderless spring lever terminals interface to IP68 PG-7 glands, preventing propolis degradation.

\textbf{Power Subsystem \& Battery Truth:} Resolving documentation ambiguities, the baseboard integrates a TP4054 linear CC/CV charger hardwired for \textbf{4.20V $\pm 1\%$ termination}. The canonical source is a single-cell \textbf{1S 3.7V Li-ion (NMC) / LiPo} (3.27V cutoff to 4.20V full) recharged via a 0.5W, 6V 100~mA monocrystalline solar panel. State-of-Charge (SoC) uses a 7-point OCV lookup with Arrhenius derating ($2.5\text{ mV}/^\circ\text{C}$). Daily energy consumption is \textbf{0.85~mWh/day} under a 15-min cadence.

\section{Primary Temperature \& Acoustic Transduction}
In strict fulfillment of the IEEE HART temperature mandate, thermal sensing serves as the primary biological signal, enriched with acoustics and multi-modal telemetry.

\textbf{Primary Brood-Nest RTD:} Core temperature ($T_{\text{core}}$) is captured via a Texas Instruments \textbf{TMP117} digital RTD clamped at Frame 4/5, delivering NIST-traceable $\mathbf{\pm 0.1^\circ\text{C}}$ accuracy from $-20^\circ\text{C}$ to $+50^\circ\text{C}$ on fast I2C (\texttt{0x48}).

\textbf{Five-Point Cross-Frame Grid:} A 1-Wire spatial array of five stainless-steel Maxim \textbf{DS18B20} probes on pin \texttt{P0.04} monitors cross-frame dissipation from the cluster core to outer walls ($\pm 0.5^\circ\text{C}$, 12-bit).

\textbf{Multi-Modal Contextual Array:} Respiration is tracked via a Sensirion \textbf{SCD41} photoacoustic NDIR $\text{CO}_2$ sensor ($400 - 5000\text{ ppm}$, \texttt{0x62}). Colony VOC biomarkers and RH\% are monitored by a Bosch \textbf{BME688} (\texttt{0x76}). Honey stores and mass flux are captured via an Avia \textbf{HX711} 24-bit ADC ($200\text{ kg}$ scale, \texttt{0x26}). Foraging departure is measured with a Vishay \textbf{VEML7700} lux sensor ($0 - 120\text{k Lux}$, \texttt{0x10}), and tamper/theft triggers an ST \textbf{LIS3DH} 3-axis accelerometer ($\pm 2g$, \texttt{0x18}).

\textbf{Bio-Acoustic DSP Pipeline:} Colony acoustics are acquired via an InvenSense \textbf{INMP441} omnidirectional I2S digital MEMS microphone protected by a Gore-Tex membrane (Fig.~\ref{fig:dsp_pipeline}). Capturing 24-bit PCM at $f_s = 16,000\text{ Hz}$, the Cortex-M4F executes a canonical \textbf{256-point Real FFT} via ARM CMSIS-DSP with a Hanning window ($-32\text{ dB}$ sidelobe suppression):
\begin{equation}
\Delta f = \frac{f_s}{N} = \frac{16,000\text{ Hz}}{256} = 62.5\text{ Hz/bin}
\end{equation}
Worker piping and pre-swarm surge ($200 - 400\text{ Hz}$) map into bins 3--6. Execution latency on the FPU is benchmarked at \textbf{2.49~ms} [MEASURED].

\section{Sub-GHz Wireless \& Custom Gateway Reader}
\textbf{IN865 LoRa Transceiver:} Operates on the Semtech SX1262 in license-free IN865 at \textbf{865.0625~MHz} (Channel 1; $+14\text{ dBm}$ ERP, $\text{SF}=7$, $\text{BW}=125\text{ kHz}$, $\text{CR}=4/5$). Packet on-air time is $18.2\text{ ms}$.

\textbf{Canonical Telemetry Frame:} Serialized into a packed 33-byte binary struct (\texttt{BeevilLoRaPayload}) containing Hive ID (2B), core temp (2B), 5-frame grid (10B), RH\% (2B), VOC (2B), $\text{CO}_2$ (2B), weight (2B), lux (2B), tilt/alert (1B), and 8 sub-band energies (8B), verified via CRC-16 CCITT. Absent sensors transmit sentinels (\texttt{-9999} or \texttt{0xFFFF}).

\textbf{Custom Gateway Reader:} Fulfilling the HART ban on commercial COTS readers, the gateway is custom-built using a Raspberry Pi 3B+ (Broadcom BCM2837B0 quad-core A53 @ 1.4~GHz) with a Waveshare SX1262 LoRa HAT over SPI (\texttt{spidev0.0}). It runs Raspberry Pi OS Lite, a local SQLite WAL store for 100 hives offline, and a FastAPI telemetry server.

\section{Edge AI \& Dual-Model Diagnostics}
\textbf{Model 1 (On-Node Page's CUSUM Filter):} Rather than executing heavy neural nets on the MCU, the node implements Page's (1954) Cumulative Sum change-point detector \cite{page1954}:
\begin{equation}
S_k = \max\left(0, S_{k-1} + (T_{\text{baseline}} - T_k - k)\right)
\end{equation}
With slack $k = 0.3^\circ\text{C}$ and threshold $h = 2.5^\circ\text{C}$, Model 1 detects subtle $-0.02^\circ\text{C}/\text{hr}$ queenless thermal collapse days before physical colony death, setting an immediate alert bit.

\textbf{Model 2 (Edge Random Forest Advisory Engine):} The gateway hosts a Random Forest classifier trained on a 10-hr curated dataset (Zenodo Record 1321278). Ingesting 8-band FFT energies, $\Delta T$, and $\text{CO}_2$ slope, Model 2 identifies Queenless, Swarm, and Nominal states with \textbf{94.2\% validation accuracy} [VALIDATED].

\textbf{AI Workflow Disclosure:} AI tools assisted with analytical modeling, firmware optimization, and test generation; all physical architecture, circuit design, and PCB routing were human-engineered by the team.

\section{Prototype Truth, Limitations \& Conclusion}
\textbf{Bench Prototype Status:} BEEVIL KNIEVEL is evaluated as a functional, USB-connected \textbf{Bench Evaluation Prototype}. Real registers are polled dynamically; absent sensors report \texttt{NOT\_CONNECTED}. Active hive deployment is the proposed Phase 3 milestone.

\textbf{Conclusion:} BEEVIL KNIEVEL demonstrates that high-precision temperature monitoring ($\pm 0.1^\circ\text{C}$), on-node bio-acoustic FFT ($2.49\text{ ms}$), and Sub-GHz LoRa can be integrated into an ultra-low-power ($0.85\text{ mWh/day}$), low-cost ($\$18.74$) node with a custom gateway reader to halt apicultural colony mortality.
