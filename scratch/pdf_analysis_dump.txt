The sensor node performs local acoustic spectral feature extraction using ARM CMSIS-DSP followed by an int8 quantized 1D-CNN model executed via
TensorFlow Lite Micro.
MATHEMATICAL FORMULATIONS & EXECUTION PIPELINE:
1. Acoustic Windowing: 2048-sample audio buffer sampled at 16 kHz (128 ms window) is multiplied by a Hanning Window (w[n] = 0.5 * (1 - cos(2 * π * n /
(N-1)))) to eliminate spectral leakage.
2. CMSIS-DSP Fast Fourier Transform: Executed using arm_rfft_fast_f32() on Cortex-M4F in 14.2 ms, producing 128 power spectral density bins (X[k]
= sum(x[n] * w[n] * e^(-j*2*π*k*n/N))).
3. Mel-Frequency Cepstral Coefficients (MFCC): Bins are passed through a 13-band triangular Mel filterbank and Discrete Cosine Transform (DCT) to yield
13 MFCC coefficients.
4. Multimodal Feature Fusion: Concatenates [TMP117 Temp, SHT45 Hum, BME688 Gas, Accel Vibration, Light, Peak Acoustic Hz, MFCC0-9] into a 16-
element normalized feature vector (V16).
5. TensorFlow Lite Micro int8 Inference: 1D-CNN (16 -> Conv1D(8) -> ReLU -> Dense(4)) evaluates in 8.5 ms (32 KB RAM Arena footprint), outputting
colony health states:
Class 0 (Normal): Baseline brood thermoregulation (34.5°C to 35.5°C).
Class 1 (Heat Stress): Thermal spike >36.5°C, triggering fan ventilation alert.
Class 2 (Swarming Risk): Acoustic energy concentrated at 110 Hz - 140 Hz.
Class 3 (Queenless Piping): High-pitch acoustic piping spikes at 225 Hz - 285 Hz.
Step 1-3: Multi-Modal Data Sensing & Preprocessing
HARDWARE DRIVERS
Reads TMP117 (±0.08°C), SHT45, BME688, LIS2DW12, OPT3001, ICS-43434. Applies median window filtering & NIST calibration.
