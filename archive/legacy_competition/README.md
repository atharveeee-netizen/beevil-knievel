# Archived Legacy Competition Artifacts

This directory contains legacy presentation, video generation, and report scripts from earlier IEEE competition submissions (October 2026).

These files are preserved strictly for historical reference:
- `build_2page_pictorial_report.py`: Generated legacy 2-page project summaries.
- `generate_impact_summary_slide.py`: Generated presentation slides.
- `build_problem_statement_video.py`: Assembled video demo slides.
- `MATLAB_FIGURE_INDEX.md`: Historical index of early MATLAB figures.

> [!WARNING]
> These archived files may contain early project estimates (e.g., initial 4.2 km free-space/two-ray line-of-sight estimates or legacy heuristic thresholds) that have been superseded by the rigorous Q1 journal analytical canopy propagation model (ITU-R P.833 / Weissberger: 0.58 km SF7 / 0.92 km SF10) and frozen Stratified Group k-Fold multi-modal benchmarks in `paper_q1/`.
